# 📦 Supply Chain & Operational Performance Analysis

## Objective

This project proposes a data-analytics solution to examine order, sales, profitability and delivery performance using
the DataCo supply-chain dataset. The analysis is intended to help decision-makers understand where revenue and
profit are generated, how delivery outcomes vary across markets and shipping modes, and which product
categories or customer segments deserve further investigation.

## Dataset Used

The dataset used in this project is the DataCo Smart Supply Chain Dataset, sourced from Kaggle. It contains comprehensive supply chain and e-commerce operational data, covering order transactions, customer information, product details, sales, profitability, shipping operations, and delivery performance.

- DataCo Supply Chain Dataset – Kaggle([https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis](https://www.kaggle.com/code/shashankmkadiwal/dataco-smart-supply-chain-eda/input))

## Technologies 

- **Python(Pandas):** Data Cleaning and Manipulation
- **Matplotlib:** Data Visualization and EDA
- **PostgreSQL:** Data Storage and SQL Analysis
- **Power BI:** KPI Calculations Interactive Dashboard Development
